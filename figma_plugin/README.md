# Auto GUI Spec Builder (Figma Plugin)

This plugin creates a single frame from a JSON spec.

## Install

1) Open Figma Desktop.
2) Plugins -> Development -> Import plugin from manifest...
3) Choose `figma_plugin/manifest.json`.

## Run

1) Plugins -> Development -> Auto GUI Spec Builder
2) Paste JSON and click Build

## Supported nodes

- rect: rectangle with fill and optional radius
- text: text node with color and font size
